# 排版规范

> 来源：电子科技大学研究生院 gr.uestc.edu.cn《研究生学位论文撰写规范》。
> 下面所有数值都是硬指标，不是建议。生成文档时逐条对照。

## 一、页面与印刷

| 项 | 值 |
| --- | --- |
| 纸张 | A4（210 × 297 mm） |
| 页边距（左 / 右 / 上 / 下） | 均 **30 mm（3.0 cm）** |
| 页眉距边界 | 20 mm |
| 页脚距边界 | 20 mm |
| 装订 | 左侧装订 |
| 印刷 | 中文摘要之前的前置部分单面；之后双面 |

## 二、字体与字号

**总原则**：中文**宋体**，数字与英文 **Times New Roman**，各级标题**黑体**。中文用黑体或加粗的地方，对应的数字与英文用**加粗 Times New Roman**。

字号换算：二号 22 磅｜小二 18｜三号 16｜小三 15｜四号 14｜小四 12｜五号 10.5｜小五 9。

| 内容 | 字体 | 字号 | 对齐 | 段前 | 段后 |
| --- | --- | --- | --- | --- | --- |
| 一级标题（章） | 黑体 | 小三 | 居中 | 24 磅 | 18 磅 |
| 二级标题 | 黑体 | 四号 | 顶格左对齐 | 18 磅 | 6 磅 |
| 三级标题 | 黑体 | 四号 | 顶格左对齐 | 12 磅 | 6 磅 |
| 四级标题 | 黑体 | 小四 | 顶格左对齐 | 12 磅 | 6 磅 |
| 正文 | 宋体 + TNR | 小四 | 两端对齐，首行缩进 2 全角字符 | 0 | 0 |
| 页眉 | 宋体 + TNR | 五号 | 居中 | 0 | 0 |
| 页码 | TNR | 小五 | 居中 | 0 | 0 |
| 脚注 | 宋体 + TNR | 小五 | 两端对齐 | 0 | 0 |

| 表格（表内文字） | 宋体 + TNR | 五号 | 居中 | 0 | 6 磅 |
| 表题 | 宋体 + TNR | 五号 | 居中 | 12 磅 | 6 磅 |
| 图表附注 | 宋体 + TNR | 五号 | 顶格 | 6 磅 | 6 磅 |
| 公式 | 宋体 + TNR | 小四 | 居中 | 6 磅 | 6 磅 |
| 公式编号 | 宋体 + TNR | 小四 | 右对齐 | 6 磅 | 6 磅 |

## 三、行距

- 从中文摘要到论文最后一页，**所有段落和标题行距取固定值 20 磅**。不是单倍，不是 1.5 倍，是「固定值 20 磅」。
- **图、表、公式例外，统一单倍行距。**
- 目录、参考文献行距同样固定 20 磅；一篇参考文献不得从中间断开跨页。

## 四、标题

- 一级标题：章序用**中文数字**，章序与章名之间空 1 个半角字符 —— `第一章 绪论`。
- 二级及以下：节序用**阿拉伯数字**，顶格书写，序与标题名之间空 1 个半角字符 —— `3.2 实验装置和方法`、`4.1.2 测试结果`、`5.3.4.1 协商系统`。
- 标题阐述内容**另起一段**书写。
- 标题不加标点符号，尽量不用英文缩写。
- **各级标题不得置于页面最后一行**（必须与下段同页）。
- 两个标题之间没有正文时，第二个标题的段前距设为 0 磅。

## 五、图

- 居中放置，按章连续编号：`图 2-5`。
- 图题在图**正下方**，五号居中；图题超过一行时两端对齐，左右缩进 4 字符。
- 分图题置于主图题之后，分图号用 `(a)` `(b)`。
- 图内中文宋体、英文数字 TNR，**10.5 磅**（与图题一致）。
- 图应自明：只看图、图题、图例就能懂，不必读正文。
- 正文中必须先有「如图 2-5 所示」，再出现图。引用他人图时，图题右上角标文献序号。

## 六、表

- **三线表**，居中，按章连续编号：`表 3-2`。
- 表题在表**上方**，五号居中。
- 表中物理量、符号用**斜体**。
- 表有附注时用英文大写字母编号，写在表下方。
- 正文中必须先有「见表 3-2」。

## 七、公式

- 居中，按章连续编号：`(5-1)`。
- **编号右对齐，编号前不加引导线**（不要用 `……(5-1)` 或制表位点点点）。
- 公式与编号同一行；段前段后各 6 磅，单倍行距。
- 公式中变量斜体，函数名与单位正体。

## 八、页眉与页码

**页眉**：宋体五号居中，页眉线为**单横线、线宽 0.75 磅**。

- 中文摘要、ABSTRACT、目录、图目录、表目录、主要符号表、缩略词表：页眉为**该部分标题**。
- 从第一章第 1 页起：**奇数页页眉 = 本章标题**（如「第一章 绪论」）；**偶数页页眉 = 电子科技大学硕士学位论文**（博士则为博士学位论文）。

**页码**：页面底端居中，TNR 小五。

- 前置部分（摘要至缩略词表）：**罗马数字，从 I 起**连续编排。
- 第一章起：**阿拉伯数字，从 1 起**连续编排。

## 九、引用与参考文献

- **顺序编码制**。正文标注放在所引内容最后一个字的**右上角**，方括号，**12 磅上标**。
- 同一处多篇：`[1,5,14-17]`。
- 文献作为句子成分时（如「由文献[8,10-13]可知」），用 12 磅正文字号与正文排齐，不做上标。
- **不得把引用标注放在各级标题处。**
- 参考文献表：五号，两端对齐，**悬挂缩进**，行距固定 20 磅。

## 十、标点与中英混排

- 中英混排时，除小数点、分图序号、公式序号外，**统一用全角标点**（，：（）""）。
- 纯英文段落按英文习惯用半角标点，并规范使用空格。
- 中文与英文之间保留一个半角空格。

## 十一、其他排版禁忌

- 只有一两行文字的段落，不得单独占一页。
- 除各章最后一页外，中间页面不得出现较大空白。
- 脚注序号用 `①…⑩`，序号的字体是正文不是上标，序号与内容之间空 1 个半角字符，悬挂缩进 1.5 字符，单倍行距。
- 定理、引理、"证明"用黑体小四，段前空 4 个半角字符，证毕用实心方块 `■` 置于末行末尾。

## 十二、怎么生成才不乱码（关键）

### 公式乱码的三个来源

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 把 `\frac{a}{b}` 当纯文本写进 docx | Word 里显示成一串 LaTeX 源码 | 转成 **OMML**（Word 原生公式对象） |
| 用 Unicode 拼公式：`∑ α₁ ≤ β` | 字体缺字形 → 豆腐块 / 大小不一 | 同上，用 OMML |
| 公式截成图片贴进去 | 不可编辑、字数不一致、缩放糊 | 同上 |

**唯一可靠的路径是 OMML。** 两条实现方式：

**① pandoc（首选）**

```bash
pandoc thesis.md -o thesis.docx --reference-doc=uestc-template.docx
```

Markdown 里的 `$E=mc^2$` 和 `$$\int_0^1 f(x)dx$$` 会被转成原生 OMML 公式。
`--reference-doc` 指向学校的官方模板 docx，样式（宋体 / 20 磅行距 / 首行缩进 / 标题层级）全部从模板继承 —— **这一步不做，格式一定跑偏**。

**② python-docx（需要精细控制时）**

python-docx 本身不生成公式，只能用 `latex2mathml` + XSLT 转 OMML，或者直接操作 XML 插入 `<m:oMath>`。成本高，除非必须，优先用 pandoc。

### 中文变字体 / 乱码的根因

docx 里每个 run 有两套字体槽：`ascii`（西文）和 `eastAsia`（中日韩）。**只设 `ascii`，中文就会掉到默认字体。**

```python
from docx.oxml.ns import qn

run.font.name = 'Times New Roman'                 # 西文
run._element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')   # 中文，漏了这行就乱
```

### 行距必须是「固定值」不是「单倍」

```python
from docx.shared import Pt
from docx.enum.text import WD_LINE_SPACING

pf = paragraph.paragraph_format
pf.line_spacing_rule = WD_LINE_SPACING.EXACTLY
pf.line_spacing = Pt(20)
```

### Python 画图里的中文

```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimSun']        # 宋体
plt.rcParams['font.serif'] = ['Times New Roman']
plt.rcParams['axes.unicode_minus'] = False          # 负号不乱
plt.rcParams['font.size'] = 10.5                    # 论文图用五号
```

保存用 `dpi=600`、`bbox_inches='tight'`，插进 Word 后保证清晰。

## 十三、交付前自检清单

逐条打勾，任何一条不过就不算交付：

- [ ] 公式在 Word 里**双击能编辑**（是 OMML，不是图片、不是文本）
- [ ] 中文没有变成非宋体，没有豆腐块
- [ ] 行距是「固定值 20 磅」，不是单倍
- [ ] 正文首行缩进是段落格式，不是敲的空格
- [ ] 一级标题居中、中文数字章序；二三四级顶格
- [ ] 图题在图下、表题在表上，都是五号居中
- [ ] 表是三线表
- [ ] 图表公式编号按章连续，正文有"如图 x-x 所示"的引出
- [ ] 页边距 3.0 cm，页眉页脚距边界 2.0 cm
- [ ] 页眉奇偶不同，页眉线 0.75 磅单横线
- [ ] 页码前置罗马、正文阿拉伯
- [ ] 参考文献悬挂缩进、顺序编码、上标 12 磅
