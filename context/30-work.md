# 工具链

## 语言

| 语言 | 用途 | 水平 |
| --- | --- | --- |
| **Python** | 数据处理、绘图、脚本、AI 模型 | 日常主力 |
| **MATLAB** | RFIC 建模、仿真、数值计算 | 日常主力 |
| 中文 | 母语 | — |
| 英语 | 读文献、写论文摘要、查手册 | 可读写 |

> 给代码默认用 Python；涉及 RF 仿真、矩阵运算、控制理论时 MATLAB 更顺手，可按场景选。

## 软件

| 用途 | 用什么 |
| --- | --- |
| 文档 | **WPS** / Microsoft Office（两者都在用，交付时优先给 `.docx`，兼容性最好） |
| 绘图 | Python matplotlib |
| 网页 | HTML / CSS / JS（原生优先） |
| AI 助手 | **WorkBuddy**、ChatGPT、Gemini、DeepSeek |

## 我的典型工作流

```
读文献 / 想清楚问题
  → 用 AI 问概念、核对理解（要一句话答案）
  → Python / MATLAB 做仿真、画图
  → 需要交付时，让 AI 生成 Word 或 HTML
  → 自检：格式、公式、部署
```

## 我卡在哪

- 机械性的写作与排版（学位论文格式反复出错）。
- 网页从「能跑」到「能上线」之间的那一段，AI 经常不说清楚。

## 协作约定

- 给方案时默认**我不在场**：假设我要拿它直接执行，每一步都要能落地。
- 涉及外部动作（发邮件、发到网上、改线上）先问我。
- 涉及本地文件：读可以随意，写之前说一声。
- 交付格式：**默认 `.docx`**（WPS 和 Office 都能开），PDF 用于定稿分发。
