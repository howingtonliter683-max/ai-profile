# 术语与代号

> 作用：省掉每一次对话开头「你说的 X 是指什么」的来回。
> 只收**有歧义**的词。行业通用到不需要解释的不要收。

## RFIC 常用缩写（我默认你会这些）

| 缩写 | 全称 | 中文 |
| --- | --- | --- |
| RFIC | Radio Frequency Integrated Circuit | 射频集成电路 |
| PA | Power Amplifier | 功率放大器 |
| LNA | Low Noise Amplifier | 低噪声放大器 |
| MMIC | Monolithic Microwave IC | 单片微波集成电路 |
| PDK | Process Design Kit | 工艺设计套件 |
| S11 / S22 | input / output reflection coefficient | 输入 / 输出反射系数 |
| S21 | forward transmission | 正向传输系数（增益） |
| VSWR | Voltage Standing Wave Ratio | 电压驻波比 |
| Γ | reflection coefficient | 反射系数 |
| load-pull | load-pull measurement | 负载牵引 |
| P1dB | 1 dB compression point | 1dB 压缩点 |
| Psat | saturated output power | 饱和输出功率 |
| PAE | Power Added Efficiency | 功率附加效率 |
| IIP3 / OIP3 | input / output third-order intercept | 三阶交调截点 |
| ACLR | Adjacent Channel Leakage Ratio | 邻道泄漏比 |
| EVM | Error Vector Magnitude | 误差矢量幅度 |
| DPD | Digital Pre-Distortion | 数字预失真 |
| ET | Envelope Tracking | 包络跟踪 |
| HB | Harmonic Balance | 谐波平衡（仿真） |
| EM | Electromagnetic | 电磁（仿真） |
