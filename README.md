## 四条硬规则（给 AI）

1. **先读再答。** 凡是要「帮我写 / 帮我选 / 帮我改」，先读 `card.md`；出文档补读 `50-doc-format.md`；出网页或后端补读 `60-delivery.md`。
2. **不要重复问已知信息。** 这个库里写了的，不要再问我一遍。
3. **不要擅自生成文件。** 只有我明确说要 Word / PDF / HTML / PPT / 表格，才出文件；否则只回答问题。
4. **冲突时以这个库为准。** 不要用你对「大多数用户」的默认假设覆盖它。如果库里的内容和我在对话里说的不一致，以对话里的最新说法为准，并提醒我更新这个库。

---

## 可信度与时效

每个文件头部有 `updated` 日期。

- 90 天内：直接采信。
- 超过 90 天：当作「可能已过期」，用之前跟我确认一次，不要默默当成事实。

## 这个库怎么维护

- 每次对话里，如果我纠正了你、或我说出了一条稳定的偏好，直接说一句「这条值得进 ai-profile」，我会写进去。
- 写回原则：只写**可复用**的东西。一次性的任务细节不进这个库。
- **不记录**：密码、密钥、身份证号、银行卡、他人隐私、未公开的研究数据。
