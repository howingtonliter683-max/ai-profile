# 决策：（一句话说清选了什么）

## 背景

当时面对的是什么问题、什么约束。写事实，不写评价。

## 选项

| 方案 | 好处 | 代价 |
| --- | --- | --- |
| A | | |
| B | | |

## 决定

选了什么，从哪天开始生效。

## 为什么

**这是整篇最重要的部分。** 写清楚哪个约束压倒了哪个好处。如果是因为「当时没时间」，就写没时间。

## 什么情况下我会反悔

写清楚这个决定失效的触发条件，例如：

- 团队超过 N 人
- 月成本超过 X
- 这个第三方服务涨价或停止维护

> 这一段让未来的你能判断「现在是不是该重新考虑了」，而不是无脑沿用。
