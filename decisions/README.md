# 决策记录

记录**为什么**，不记录**做了什么**。做了什么 git 里都有，为什么只有人记得，而过半年就忘了。

## 为什么值得记

半年后你（或者某个 AI）会问：「当初为什么不用那个看起来更合理的方案？」

没有这一页，答案就是「不知道，反正当时有原因」。有了这一页，答案是一段具体的历史约束。

## 什么时候写

满足任意一条就写：

- 这个决定**改起来很贵**（换框架、换供应商、换方向）
- 这个决定**看起来反直觉**（外人/未来的你第一反应会是「为什么不选另一个」）
- 这个决定**否掉了某个明显选项**（否则会有人反复建议它）

不够格的不要写。记录一多就没人读了。

## 命名

`YYYY-MM-DD-一句话.md`，例如 `2026-11-25-不用容器部署.md`
